# 추가 예측 7 (2026-09-20T12:09:12+09:00) — 어려운 경우: 효과가 T와 비슷한 진짜(연속) 시간 차이
기준 크기 100000B와 비교 크기 112288/140000/200000B (원본 펌웨어, 각 T에서 2회). 진짜 차이 d = 0.814 ms/KB * (Δ크기/1024):
  d(112288)=9.8ms, d(140000)=31.8ms, d(200000)=79.5ms
T in {0.005, 0.02, 0.05, 0.1}. gap(T)=평균(비교)-평균(100000).
예측(양자화 모델): 모든 조건에서 gap(T)가 [d-T-8, d+T+8] 안. 따라서 T<=d/2 인 조건에서만 gap>=d/2 가 보장되고,
  T>d 인 조건(예: d=9.8이면 T>=20, d=31.8이면 T>=50)에서는 gap이 0 또는 약 T로 갈려 "사라진 것처럼" 보일 수 있음(검정의 유효 범위 밖).
반증: 위 범위를 벗어나는 gap이 다수(3건 이상) 나오면 양자화 모델 기각.
